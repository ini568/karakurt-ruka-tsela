# КАРАКУРТ: Рука цела

Игра на HTML5 Canvas 2D: паук против человека в ночной комнате.

**Цель:** продержаться **180 секунд** (таймер 3:00), не потеряв всё здоровье. Начальное здоровье — **3**. Если таймер дошёл до нуля и паук жив, вы видите финал «Рука цела». Если здоровье упало до 0, партия проиграна.

**Что убивает паука.** Каждое попадание отнимает 1 здоровье. После удара паук получает временную неуязвимость.

| Угроза | Что происходит |
| --- | --- |
| Рука (шлепок) | Короткий удар ладонью по прямоугольной зоне |
| Стакан | Накрывает зону и остаётся активным 1,05 с (дольше остальных угроз) |
| Сметающий удар | Широкая полоса через поле |

Атаки целятся туда, где паук находится в момент появления предупреждения. Сначала зона показывается контуром (фаза `warning`, безопасна), затем следует удар (фаза `active`). Урон наносит только активная фаза удара. Пока активно предупреждение, уйдите из зоны.

**Очки.**

| Событие | Очки |
| --- | --- |
| Каждая секунда выживания | +5 |
| Уклонение: атака закончилась, паук вне зоны и не в неуязвимости | +25 (и +1 к счётчику уклонений `dodges`, один раз на угрозу) |
| Поймана муха | +100 (и +14 шёлка) |
| Победа: дожили до конца таймера (0:00) | +500 |
| Попадание угрозы | −10 (счёт не опускается ниже 0) |

Сложность нарастает по ходу раунда. Детальные параметры, кривая интенсивности и обоснование баланса описаны в [docs/balance.md](docs/balance.md) без дублирования в данном руководстве.

## Первые 30 секунд

- Не оставайтесь на одном месте. Атака наводится на координаты паука в момент предупреждения, поэтому при пассивной тактике паук быстро погибает.
- Увидев контур предупреждения (фаза `warning`), немедленно покиньте опасную зону. Предупреждение урона не наносит — урон начинает засчитываться только после перехода в активную фазу (`active`).
- Стакан остаётся опасным в течение 1,05 с. Не заходите в его зону, пока он остаётся в активной фазе.
- Паутина цепляется к ближайшей точке крепления в радиусе 180 игровых пикселей от прицела. Раскачивайтесь и отпускайте нить, чтобы передвигаться по комнате с набранной скоростью.
- Шёлк расходуется на выпуск паутины и рывок (Shift), а восстанавливается в свободном полёте/беге без натянутой нити и при ловле мух. Сохраняйте резерв шёлка на рывок, чтобы выскочить из зоны поражения перед ударом.
- Мухи приносят +100 очков и +14 шёлка, но не следует бросаться за ними в активную зону поражения: потеря 1 здоровья и штраф −10 очков превышают выгоду.

## Управление

| Действие | Клавиатура и мышь |
| --- | --- |
| Перемещение | WASD или стрелки |
| Прицеливание | Перемещение указателя мыши по игровому полю |
| Паутина | Удерживайте ЛКМ или Пробел (Space); отпустите, чтобы оборвать нить и сохранить набранный импульс |
| Рывок | Shift (при достаточном запасе шёлка) |
| Пауза | Escape (повторное нажатие или кнопка «Продолжить» возвращает в игру). Пауза также включается при потере окном фокуса или скрытии вкладки |
| Звук | Кнопка управления звуком в интерфейсе |

На паузе игровое время, таймер и счёт замораживаются. После возобновления отсчёт продолжается ровно с прежнего значения. После поражения или победы кнопка новой партии полностью перезапускает раунд с 3 единицами здоровья, таймером 3:00 (180 с) и счётом 0.

Логический размер холста — 1280×720 с адаптивным масштабированием под окно с сохранением пропорций.

Сенсорное управление (**не проверено на реальных устройствах**): левая половина экрана задаёт движение, правая — прицеливание и удержание нити. Кнопки «Паутина ◎» и «Рывок» дублируют соответствующие действия.

## Локальный запуск

Игра представляет собой статическое клиентское веб-приложение: `index.html` загружает модули `src/main.js` и таблицу стилей `src/art/styles.css`. Сборка, бандлеры и `npm install` не требуются. Браузерные ES-модули требуют отдачи по протоколу HTTP (открытие напрямую через `file://` блокируется политикой безопасности браузеров).

### Запуск локального HTTP-сервера

1. Откройте терминал в корневой папке проекта (где находится `index.html`).
2. Запустите любой локальный статический HTTP-сервер, например через Python 3:

   ```sh
   python -m http.server 53712 --bind 127.0.0.1
   ```

   (или с автоматическим выбором свободного порта: `python -m http.server 0 --bind 127.0.0.1`, либо `python3` / `py -3` в зависимости от установленного в системе интерпретатора).
3. Перейдите в браузере по адресу `http://127.0.0.1:53712/` (или по порту, выведенному сервером) и нажмите «Начать ночь».
4. Для остановки сервера нажмите `Ctrl+C` в окне терминала.

## Звук и локальные сохранения

Звуковые эффекты генерируются процедурно через Web Audio API без загрузки внешних аудиофайлов. Для инициализации звука требуется первое взаимодействие пользователя (нажатие кнопки «Начать ночь» или клик по экрану).

Рекорды партии сохраняются в `localStorage` браузера по ключу `karakurt.progress.v1` (структура: версия схемы 1, лучший счёт `bestScore`, наибольшее время выживания `bestSurvival`, количество побед `wins`). При отказе или блокировке `localStorage` игра сохраняет полную работоспособность в пределах текущей сессии.

## Ограничения и статус проверки (не проверено)

Следующие характеристики и сценарии **не являются гарантированными и помечены как не проверенные**:
- **Мультитач и мобильные устройства**: поведение экранного сенсорного управления, жестов и настоящего мультитача на смартфонах и планшетах на реальном оборудовании не валидировалось.
- **Звук**: слышимость, тембры и корректность синтеза звука в различных браузерах на реальных аудиоустройствах не подтверждены (автоматические тесты используют заглушку Web Audio API).
- **Производительность и FPS**: кадровая частота (60 FPS), отзывчивость, плавность Canvas-рендера, нагрев и потребление памяти на слабых и портативных устройствах не замерялись и не гарантируются.

Фактический статус прохождения всех проверок и незакрытые вопросы фиксируются в документе [tests/acceptance.md](tests/acceptance.md).

## Проверки для разработчика

Для запуска автоматических тестов требуется Node.js с поддержкой встроенного раннера `node:test` (Node.js 20+). Внешние зависимости устанавливать не требуется.

### Полный набор проверок

Для запуска полного цикла валидации проекта выполните единую цепочку команд из корневой директории:

```sh
npm test && npm run check && node tests/art.check.mjs && node tests/input.check.mjs && node tests/game.check.mjs && node tests/mechanics.check.mjs && node tests/regression/run.mjs
```

Каждая проверка завершается с ненулевым кодом при возникновении ошибок или нарушении контрактов.

### Назначение отдельных проверок

| Команда | Назначение |
| --- | --- |
| `npm test` | Тесты игровой модели (`node --test tests/model.test.mjs`) |
| `npm run check` | Статическая валидация проекта (`node tools/check.mjs`), печатает `CHECK OK` |
| `node tests/art.check.mjs` | Проверка контрактов рендера и заглушек Web Audio |
| `node tests/input.check.mjs` | Проверка жизненного цикла обработчиков и событий ввода |
| `node tests/game.check.mjs` | Длительная симуляция игровых контрактов модели |
| `node tests/mechanics.check.mjs` | Проверка механики паутины, генерации угроз и начисления очков |
| `node tests/regression/run.mjs` | Полный запуск регрессионного набора тестов (печатает `REGRESSION OK`) |

## Развёртывание

Подготовьте и проверьте отдельный публикуемый артефакт:

```sh
node tools/prepare-pages.mjs && node tests/regression/publish/artifact.mjs
```

Размещается только содержимое `dist/`: `index.html`, `.nojekyll` и `src/`. `package.json`, тесты и служебные файлы сайту не нужны. Серверных API и баз данных нет. Ссылки работают в корне домена и в подпапке репозитория.

Пошаговые инструкции GitHub Pages (ручной workflow), itch.io и проверки настоящего публичного URL: [docs/publishing.md](docs/publishing.md). Готовый локальный артефакт ещё не является публичной ссылкой для модерации.
