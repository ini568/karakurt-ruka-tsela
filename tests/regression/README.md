# Независимые Node-регрессии

Запуск из корня проекта (без установки пакетов):

```sh
node tests/regression/run.mjs
```

Используются только ES-модули и `node:assert/strict`. Runner выполняет все четыре набора, печатает ошибки утверждений в stderr и устанавливает ненулевой exit code при любой ошибке. Единственная финальная строка `REGRESSION OK` появляется только после успеха всех наборов. PASS-строки других наборов не означают полный успех, если есть FAIL.

Существующие тесты и приёмочные фикстуры не изменяются. Новых экспортов, полей состояния, DOM ID или зависимостей от продукта не требуется. Набор импортирует настоящие `createGame`, `stepGame`, `readProgress`, `serializeProgress`, `burst`, `createInput`, `mountGame`. Поведение симуляции, ввода, сохранения и клиентского цикла не скопировано в тесты.

## Что проверяется

| Файл | Наблюдаемое поведение |
| --- | --- |
| `model.mjs` | Переход в won/lost через существующие публичные поля; один терминальный event; бонус +500 только один раз; после завершения все поля заморожены, кроме очищаемого outbox events; повторная сериализация не меняет результат; новая партия независима и возвращает 3 жизни/180 секунд/нулевой счёт. |
| `model.mjs` | NaN, ±Infinity, отрицательное/нулевое время и значения нечислового типа не меняют физику, RNG, шёлк, счёт или время; конечный огромный dt ограничивается обычным максимальным шагом. Проверяется весь снимок состояния, а не только отсутствие исключения. |
| `model.mjs` | Повреждённый JSON, неверная версия/форма и бесконечные/отрицательные/строковые рекорды; сохранность неповреждённых полей и корректный round trip. |
| `input.mjs` | Mouse/touch pointerup, pointercancel, lostpointercapture (включая событие без pointerType); вторичная кнопка мыши не отпускает ЛКМ; отказ setPointerCapture не обрывает ввод; независимое отпускание move/web в обоих порядках. |
| `input.mjs` | Прямой reset и blur очищают клавиши, оба контакта и ещё не потреблённый рывок; движение отменённого указателя не возрождает контакт; dash потребляется однократно; destroy удаляет слушатели и сенсорные элементы. |
| `client.mjs` | Настоящий mountGame запускается при повреждённом и недоступном localStorage; blur/visibilitychange ставят паузу; кадры паузы и первый кадр продолжения не перескакивают по времени; пассивная партия реально завершается; запись результата ровно одна при доступном storage; повтор восстанавливает начальный HUD; RAF не удваивается; destroy/remount очищают ресурсы. |
| `mechanics.mjs` | Последний шаг ограничен остатком до 180 секунд; extreme finite aim даёт конечный ненулевой рывок; burst с огромным/невалидным count не создаёт неограниченное число частиц. |
| `mechanics.mjs` | Три полные партии seed 1, 47, 987654 выигрываются активным контроллером; конечность чисел игрока и пределы числа угроз/мух/частиц проверяются на каждом шаге. |

В терминальных модельных сценариях намеренно подготавливаются публичные `time`/`hp`: это тест границы завершения, не доказательство прохождения партии. Отдельный активный контроллер **не меняет** состояние: читает предупреждение, выбирает ближайшую доступную сторону прямоугольника с запасом радиуса и подаёт обычные moveX/moveY. Он не повторяет генератор угроз, физику или подсчёт очков. Три seed доказывают достижимость победы в этих случаях, но не универсальную проходимость всех seed или комфорт сложности человеку.

## Граница заглушек — что НЕ доказано

`harness.mjs` предоставляет только доставку событий слушателям, дерево элементов/атрибутов, очередь RAF и localStorage. Это не браузер: отсутствуют bubbling, hit testing, настоящие pointer capture, фокус, CSS/layout и политика автозапуска звука. События отмены отправляются явно; проверяется реакция кода на них, а не то, как конкретная ОС их доставляет. Два синтетических pointerId подтверждают независимость логики, **не настоящий мультитач**.

В клиентской проверке canvas имеет нулевой размер: реальный app сам пропускает draw. Рендерер не заменяется, но также не исполняется. Проверки HUD читают публичные dataset.hud и текст текущих элементов; позиция, читаемость, доступность и внешний вид не оцениваются. Аудиоконтекст не создаётся: звука на слух и работы реального аудиоустройства этот прогон не подтверждает. Доступное хранилище — Map-подобная заглушка, не реальное сохранение после перезагрузки браузера.

Отдельная браузерная/устройственная приёмка остаётся необходимой:

- настоящий клавиатурный фокус, удержание/отпускание, Escape, переключение вкладок и возврат после долгой паузы;
- доставка pointercancel/lostpointercapture при системных жестах, выходе указателя и смене ориентации;
- одновременные пальцы в движении/паутине/рывке, отсутствие конфликта со скроллом и масштабированием;
- звук на слух, mute/unmute, жестовая разблокировка AudioContext и отключение устройства;
- визуальные предупреждения/активные угрозы, нить и паук, reduced motion, панели на узком экране, DPR и letterbox;
- рекорд после реальной перезагрузки страницы и отказ настоящего browser storage;
- полный человеческий забег до победы, удобство управления и оценка баланса;
- FPS, задержки ввода, память, нагрев и производительность реального устройства.

## Дополнительные проверки интеграции

- `node tests/regression/audio.mjs`: заглушка AudioContext проверяет mute без создания устройства, отказ подключения/повторную попытку, очистку частично созданного сигнала и идемпотентное освобождение. Не доказывает слышимость звука.
- `node tests/regression/delivery.mjs`: исполняет настоящий `tools/check.mjs` с файловым оверлеем в памяти. Проверяет отклонение отсутствующего импорта, `node:`, JSON и отсутствующего экспортируемого имени. Исходники и фикстуры не меняет; это не HTTP/браузерная проверка.
- Обе команды прошли при итоговом интеграционном прогоне вместе с проектными npm-командами и четырьмя существующими smoke-проверками. Основной runner не включает эти две дополнительные команды автоматически.

## Фактический локальный результат исполнителя (история)

`node tests/regression/run.mjs` выполнен успешно: четыре набора, 12 PASS-групп, exit code 0, финальная строка `REGRESSION OK`. Это результат собственного Node-runner на прочитанных и интегрируемых файлах, **не финальная проверка всего проекта**. Проектные npm-команды, старые тесты и браузер в рамках этой работы не запускались; итоговый интеграционный прогон остаётся тимлиду.
